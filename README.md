# RL-Reputation

## Description

This repository contains the simulation code for the project *"Reputation-Modulated Reinforcement Learning"*. The code is organized as follows:

- **`Main scan.ipynb`** – Main driver script for running the synchronous multi-agent simulations.
- **`Different initial condition.ipynb`** – Auxiliary notebook to study the effect of initial states; launches simulations from a user‑specified initial condition.
- **`Pair approximation.ipynb`** – Companion code implementing the pair‑approximation mean‑field theory for analytical validation.

## Dependencies

- Python 3.8+
- NumPy
- Matplotlib
- Jupyter Notebook

## Usage

Run the notebooks in Jupyter Lab or Jupyter Notebook. The main results are generated by `Main scan.ipynb`; the other notebooks are for supplementary analyses.
